# Shinobi Next Generation

Jeu d'action ninja de Naruto à Boruto, entièrement dans **un seul fichier `index.html`**.

**Jouer :** https://lindcil.github.io/shinobi-next-gen/

Il réunit le meilleur de Shinobi 1 (Éternel II) et de Shinobi 2, et y ajoute l'ère Boruto. Voir `DESIGN_CHOICES.md`, `ROADMAP.md` et `PATCH_NOTES.md`.

Compter les techniques : `node tools/count_moves.js index.html`
